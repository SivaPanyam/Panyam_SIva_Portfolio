Terminal Presentation

How should the Claude-Code-inspired terminal be accessed and displayed?

A

Global Modal Overlay (Cmd+K / `~`)

A floating glass terminal window that can be summoned instantly from anywhere over the current content, similar to a command palette or Spotlight.

B

Dedicated Scroll Section

The terminal lives directly in the page flow (e.g., right below the hero). It's a permanent fixture that users scroll down to interact with.

C

Developer Slide-out Console

The terminal slides up from the bottom of the screen or in from the side, mimicking Chrome DevTools or an IDE's integrated terminal.
